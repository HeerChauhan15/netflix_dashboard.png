# netflix_dashboard.png

Netflix Data Visualization Dashboard (Tableau) <br>
📊 **Overview**
This repository contains a Tableau dashboard created to visualize Netflix's movie and TV show data. The dashboard presents insights about content distribution, genres, ratings, country-wise availability, and release trends over the years.
<br>
**Key Visualizations**
Movies & TV Shows Distribution (Pie Chart)
Content Ratings (Bar Chart)
Top 10 Genres (Horizontal Bar Chart)
Country-wise Content Distribution (World Map)
Content Release Trends by Year (Area Chart)
Detailed Info Panel (Type, Title, Rating, Duration, Genre, Description, etc.)
<br>
🔍 **Insights**
Most content falls under TV-MA and TV-14 ratings.
Documentaries and Stand-Up Comedy are among the top genres.
The USA has the highest number of available titles.
A sharp rise in content was seen between 2016 and 2019.
